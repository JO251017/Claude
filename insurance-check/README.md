# 내 보험료 30초 분석

매달 내는 보험료가 어디에 쓰이고 있는지 30초 만에 확인하는 도구입니다.
보험을 파는 사이트가 아니라, **자기 보험을 먼저 이해하게 하는 도구**로 설계했습니다.

---

## 실행 방법

빌드 과정이 없습니다. 둘 중 아무 방법이나 쓰면 됩니다.

```bash
# 1) 파일을 그대로 열기
open index.html          # macOS
xdg-open index.html      # Linux
# Windows 는 index.html 더블클릭

# 2) 로컬 서버로 열기 (모바일 기기에서 테스트할 때 권장)
python3 -m http.server 8000
# → http://localhost:8000
```

`file://` 로 직접 열어도 모든 기능이 동작합니다. ES 모듈 대신 클래식 스크립트를 쓴 이유가 이것입니다.

## 파일 구조와 역할

```
insurance-check/
├── index.html    9개 화면(인트로 · 5단계 입력 · 결과 · 신청 · 완료)의 마크업과 ARIA 속성
├── style.css     디자인 토큰(:root) · 레이아웃 · 컴포넌트 · 반응형 · 다크모드 · 모션 억제
├── app.js        Calc / Validate / Analysis / Render / Nav / Lead 6개 네임스페이스
├── README.md     이 문서
└── assets/       (현재 비어 있음. 이미지·아이콘을 추가할 자리)
```

| 네임스페이스 | 역할 | 주요 함수 |

## 구현된 기능

**입력 (5단계, 한 화면에 하나의 질문)**
- 나이 · 성별 → 월 보험료 → 보험 개수 → 보장 영역(복수 선택) → 갱신형 여부
- 보험료 입력 즉시 월 / 연간 / 10년 미리보기
- 진행률 표시 (`●━━○━━○━━○━━○` · `2 / 5`)
- 브라우저 뒤로가기로 이전 단계 복귀 (`history.pushState`)
- 입력값 검증 통과 전에는 다음 단계로 넘어가지 않음

**결과**
- 큰 숫자 히어로(월 보험료) + 카운트업 애니메이션
- 4개 카드 — 매달 / 1년 / 10년 / 가입 보험 개수
- 입력값에 따라 달라지는 요약 문장
- **커버리지 맵** — 9개 보장 영역을 균등 길이 바로 표시하고, 선택한 항목만 채웁니다
- 대분류별 커버 범위 칩 (`의료비 1/1` `중대질병 3/3` …)
- 선택한 보장 태그
- 입력에 따라 자동 생성되는 "확인해볼 항목"
- 하단 면책 문구

**상세 분석 신청**
- 이름 · 상담 방식 · 연락처 · 보험 개수 · 월 보험료 (뒤 두 개는 자동 입력)
- 연락처 자동 하이픈, 개인정보 수집·이용 동의 체크박스(필수)
- 이중 제출 방지, 전송 실패 시 입력값 보존

## 리드(신청 내용) 전송 설정

기본 상태에서는 **신청 내용이 어디에도 전송되지 않습니다.** 완료 화면만 보여줍니다.

실제로 수집하려면 `app.js` 상단 한 줄만 채우면 됩니다.

```js
var CONFIG = {
  LEAD_ENDPOINT: 'https://script.google.com/macros/s/AKfy.../exec',
  ...
};
```

값이 있으면 아래 JSON 을 `POST` 합니다.

```json
{
  "name": "홍길동",
  "contactChannel": "kakao",
  "contact": "01012345678",
  "policyCount": "6개 이상",
  "monthlyPremium": 287000,
  "annualPremium": 3444000,
  "tenYearPremium": 34440000,
  "age": 34,
  "gender": "male",
  "coverages": ["medical", "cancer", "brain", "heart"],
  "renewal": "yes",
  "submittedAt": "2026-09-18T07:00:00.000Z"
}
```

> 연락처와 보험 정보는 개인정보입니다. 수신 측에 HTTPS · 접근 통제 · 보유기간 관리가 준비된 뒤에 연결하세요.

## 계산 방식

```js
annualPremium  = monthlyPremium * 12;
tenYearPremium = monthlyPremium * 120;
```

- 표기는 `Intl.NumberFormat('ko-KR')` 기준 (`287000` → `287,000원`)
- 요약 문장의 만원 단위는 반올림하며 반드시 "약"을 붙입니다 (`3,444,000` → `약 344만원`)
- `NaN` · `Infinity` · 음수는 `Calc.safeNumber()` 에서 걸러져 화면에 노출되지 않습니다

### 입력 제한

| 항목 | 범위 | 벗어났을 때 |
|---|---|---|
| 나이 | 18 ~ 100 | 18 미만 → "만 18세 이상을 대상으로 하는 서비스입니다." |
| 월 보험료 | 1,000 ~ 5,000,000원 | 0/빈값 → "보험료를 입력해주세요." · 음수 → "0원보다 큰 금액을 입력해주세요." · 초과 → "월 보험료는 500만원 이하로 입력해주세요." |
| 보험 개수 | 1~5 또는 6개 이상 | 미선택 시 진행 차단 |
| 보장 | 1개 이상 | 미선택 시 "잘 모르겠음"도 선택 가능함을 안내 |

## 설계 원칙

### 1. 추정 금액을 실제 보험료처럼 보여주지 않습니다

보장 영역별 막대 길이는 **전부 동일합니다.** 가입 여부만 입력받는 상태에서 카테고리별로 길이를 다르게 그리면
사용자가 그것을 보험료 배분으로 오해하기 때문입니다. 선택한 항목은 채우고, 선택하지 않은 항목은 점선 빈 바로 둡니다.

화면에는 항상 다음 두 문장이 함께 표시됩니다.

> 보장 영역은 가입 여부를 기준으로 표시한 참고용 구성입니다. 실제 보험료가 각 보장에 얼마씩 배분되는지는 보험증권 확인이 필요합니다.
> 선택하지 않은 항목은 미가입을 뜻하지 않으며, 이번 입력에서 선택하지 않았다는 의미입니다.

### 2. 판단하지 않고 확인을 권유합니다

"확인해볼 항목"은 모두 `확인 필요` 또는 `참고` 상태로만 표시됩니다.
보험료의 적정 여부, 상품·회사 추천, 해지·전환 권유는 하지 않습니다.

이 원칙은 코드로 강제되어 있습니다.

```js
// 브라우저 콘솔
window.InsuranceCheck.auditCopy()   // → []  (위반 0건)
```

`auditCopy()` 는 가능한 모든 입력 조합의 분석 문구를 생성한 뒤 금지 표현
(`비싸` `저렴` `해지` `갈아타` `손해` `잘못` `추천` `절약` `가입하세` `최저가` `무조건` 등)을 정규식으로 검사합니다.

### 3. 개인정보를 최소로 받습니다

결과 확인까지는 **이름 · 전화번호 · 주민번호 · 주소 · 보험증권을 받지 않습니다.**
나이 · 성별 · 월 보험료 · 보험 개수 · 보장 카테고리 · 갱신형 여부만 받고, 전부 브라우저 안에서만 계산합니다.
연락처는 사용자가 상세 분석을 직접 신청할 때만 받습니다.

## 접근성 · 반응형

- 320 / 360 / 390 / 768 / 1280px 에서 가로 스크롤 없음
- 모든 버튼 · 입력 터치 타겟 44px 이상
- WCAG AA 명도 대비 4.5:1 — 라이트 · 다크 모드 모두 위반 0건
- 라디오 그룹 방향키 이동, 입력 필드에서 Enter 로 다음 단계
- 오류는 `role="alert"` + `aria-invalid` + `aria-describedby`
- 진행률은 `role="progressbar"` + `aria-valuetext`, 숫자 텍스트 병기
- 선택 상태는 색상뿐 아니라 `✓` 표식으로도 구분
- `prefers-reduced-motion: reduce` 시 카운트업·전환 애니메이션 비활성
- `prefers-color-scheme: dark` 대응

## 이번 MVP에서 의도적으로 제외한 것

| 제외 항목 | 이유 |
|---|---|
| 서버 · DB | 개인정보 저장 전에 처리 구조를 먼저 확립하기 위해 |
| 보험증권 파일 업로드 | 민감정보 처리 체계가 갖춰진 뒤 추가 |
| 결과 저장 · 공유 링크 | 저장 대상이 개인정보라 서버 도입과 함께 진행 |
| 로그인 · 회원가입 | 30초 완주율을 떨어뜨림 |
| 보험사 · 상품 데이터 | 특정 상품 추천으로 읽힐 수 있음 |
| 평균 보험료 비교 | 입력값만으로 좋다/나쁘다를 판단하지 않는다는 원칙과 충돌 |
| 성별 기반 계산 | 구조만 만들어두고 계산에는 사용하지 않음 |
| 빌드 도구 · 프레임워크 | MVP 단계에서 불필요 |

## 테스트

브라우저 자동 테스트(Playwright)로 120개 항목을 검증했습니다.
런타임 의존성을 0으로 유지하기 위해 테스트 스크립트는 저장소에 포함하지 않았습니다.

수동으로 확인하려면:

1. 34세 / 남성 / 287,000원 / 6개 이상 / 실손·암·뇌혈관·심혈관 / 갱신형 있음
   → 월 287,000원 · 연간 3,444,000원 · 10년 34,440,000원
2. 월 보험료 `0` → "보험료를 입력해주세요."
3. 월 보험료 `-100000` → "0원보다 큰 금액을 입력해주세요." (부호를 지우지 않고 오류로 안내)
4. 나이 `3` → "만 18세 이상을 대상으로 하는 서비스입니다."
5. 월 보험료 `9999999999` → "월 보험료는 500만원 이하로 입력해주세요."
6. 보장 `잘 모르겠음` 단독 선택 → 구성 표시 생략 + 증권 확인 안내
7. 콘솔에서 `InsuranceCheck.auditCopy()` → `[]`
