# 스마트스토어 상품 발굴·순이익 관리 도구

**엑셀 파일 하나(`관리.xlsx`)**에 입력하고, 실행 파일을 더블클릭하면 결과가 같은 엑셀에 채워집니다.

| 단계 | 하는 일 | 실행 파일 |
|---|---|---|
| 0 키워드 발굴 | 씨앗 단어 → 연관 키워드·월간 검색수·상품 수 → **덜 붐비는 키워드 순** | `0_키워드발굴` |
| 1 순이익 후보표 | 키워드·경쟁 시세·도매 원가 → **팔아서 남는 상품 후보**(통과/보류/탈락) | `1_후보표만들기` |
| 2 승인 | 엑셀에 표시한 승인을 기록 → 승인된 후보만 남김 | `2_승인가져오기` |

> 윈도우는 `.bat`, 맥은 `.command` 파일을 더블클릭합니다. 순이익은 **세전**(부가세·소득세 미반영)입니다.

## 1. 처음 한 번
1. 파이썬 3.10 이상 설치(https://www.python.org, 설치 화면에서 "Add Python to PATH" 체크)
2. `설치_처음한번` 실행 → 필요한 부품 설치 + `관리.xlsx` 생성
3. (선택) 네이버 자동 조회를 쓰려면 키 설정: `docs/RUN_REAL_API.md`

## 2. 관리.xlsx 쓰는 법
**노란 탭 = 입력하는 곳, 파란 탭 = 프로그램이 채우는 곳.** 실행할 때는 엑셀을 닫아 주세요(열려 있으면 아무것도 기록하지 않고 안내만 합니다).

| 시트 | 입력/결과 | 내용 |
|---|---|---|
| 안내 | - | 사용 순서 |
| 씨앗 | 입력 | 발굴용 넓은 단어, 분야 코드 |
| 발굴 결과 | 결과 | 연관 키워드, 월간 검색수, 상품 수, 경쟁강도. **쓸 키워드에 O** 표시 → 1단계에 자동 포함 |
| 키워드 | 입력 | 직접 검토할 키워드(발굴 결과 O와 합쳐짐) |
| 경쟁시세 | 입력 | 경쟁 판매자 가격·배송비·조사일 |
| 도매원가 | 입력 | 원가·배송비·도매처 + AI 노출 정보(스펙 Y/N, 모델명, 출고 일수, 차별점) |
| 클릭추이 | 입력(선택) | 데이터랩 월별 값. **데이터랩 자동 조회를 쓰면 비워 둠** |
| 요약 | 결과 | 한 줄 결론, 근거, 이상 징후. 맨 아래 **실행 승인**(승인/반려/보류) |
| 후보 | 결과 | 통과·보류 후보. 맨 오른쪽 **항목 승인 O/X** |
| 탈락·실패 | 결과 | 탈락 이유, 모자란 금액 |

머리글에 마우스를 올리면 칸 설명이 나옵니다.

### 매번 순서
1. (선택) `씨앗` 입력 → `0_키워드발굴` → `발굴 결과`에서 쓸 키워드에 O
2. `경쟁시세`·`도매원가` 입력 → `1_후보표만들기` (클릭추이를 네이버에서 자동으로 받으려면 `1_후보표만들기_데이터랩자동`)
3. `요약`의 실행 승인 + `후보`의 O/X 입력 후 저장 → `2_승인가져오기`

결과 사본과 기록은 `output/` 폴더에 실행마다 남습니다.

## 3. 판정 기준 (탈락 > 보류 > 통과 순으로 더 나쁜 쪽)
| 판정 | 언제 |
|---|---|
| 탈락 | 시장 가격으로 팔면 최소 마진 15%·최소 이익 2,000원을 못 맞춤 / 고객 배송비가 시장가 이상 |
| 보류 | 원가·시세 미입력, 조사일이 오래됨(시세 7일·원가 14일 초과), 클릭 추이 확인 불가 |
| 통과 | 위에 해당 없음 |

- 경고(판정 영향 없음): 배송비 비중 과다, 수량당 배송비, 표본 부족, 계절성·급등.
- **AI 노출 준비**: 네이버 쇼핑 AI가 추천 근거로 쓰는 스펙·모델명·출고일·차별점을 갖췄는지 표시(근거 `docs/ai_exposure.md`). 판정에도 반영하려면 `config.yaml`의 `ai_readiness.affects_verdict: true`.
- **경쟁강도**(발굴) = 상품 수 ÷ 월간 검색수. 낮을수록 찾는 사람에 비해 파는 상품이 적습니다.
- 모든 기준값은 `config.yaml`에서 바꿉니다.

## 4. 연습해 보기 (가상 데이터)
```
python -m src.cli --config data/sample/config.sample.yaml --workbook 관리_샘플.xlsx init --sample
python -m src.cli --config data/sample/config.sample.yaml --workbook 관리_샘플.xlsx run --as-of 2026-07-15
```
`관리_샘플.xlsx`를 열어 결과를 봅니다. (샘플 설정은 보류 사례를 보여 주려고 최소 마진만 5%로 낮춘 것입니다.)

## 5. 알아둘 점
- 네이버 API(데이터랩·검색광고·쇼핑 검색)는 공식 문서대로 만들었지만 **실제 연결은 아직 시험 전**입니다. 첫 실행 때 결과를 네이버 화면과 한 번 맞춰 보세요.
- API 키는 `.env`에만 넣습니다. 키 값은 화면·로그·엑셀·DB 어디에도 기록되지 않습니다.
- 받아온 클릭 추이 원값은 성장률 계산에만 쓰고 저장하지 않습니다.
- CSV로 쓰고 싶으면 예전처럼 `--keywords` 등 경로를 주면 됩니다(`data/templates/`).
- 개발 기록·가정: `docs/dev_log.md`. 테스트: `python -m pytest -q`.
