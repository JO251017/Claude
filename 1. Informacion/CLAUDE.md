# Informacion

개인 취미 콘텐츠 프로젝트 — 일상 기술·사물의 역사를 카드 스토리텔링 포맷으로 설명한다. 수익 목적 아님. 주제는 매번 사용자가 새로 지정하며, 후보 목록은 미리 뽑아두지 않는다.

루트 `CLAUDE.md`의 라우팅 규칙에 따라 이 프로젝트로 연결되면(예: "1: OO"), 프리픽스 뒤의 내용이 곧 "주제"다. 링크나 추가 설명을 요구하지 말고 아래 절차를 그대로 실행한다.

## 파일 구조
- `template/card-template.html` — 카드 포맷 기준 템플릿 (예시 주제: 자동차 열선시트의 역사). 구조·디자인 토큰·인터랙션의 원본. 새 주제 작업 시 이 파일을 복사해서 `DATA` 배열만 교체한다. 그 외 CSS/JS는 그대로 유지.
- `archive.html` — 완성작을 카드형 DB로 관리하는 화면. 제작은 여기서 하지 않는다 — 완성되면 링크만 등록.
- `stories/` — 완성된 주제별 카드 HTML을 저장하는 폴더. 파일명은 `stories/<슬러그>.html` (예: `stories/ice-cream-cone.html`).

## 카드 포맷 규격
- 최대 10장, 카드 1장 = 이미지 1장 + 짧은 설명(2~3문장)
- 클릭하면 다음 장으로 넘어가는 단일 카드 스택 (스크롤형 아님)
- 표준 10칸: 00표지 / 01문제 / 02아이디어 / 03최초등장(특허) / 04초기기술 / 05한계 / 06개선 / 07대중화 / 08현재 / 09미래
- 이야기가 짧으면 6~8장으로 축약 가능
- 진행바(세그먼트 클릭 이동), prev/next 컨트롤, prefers-reduced-motion 대응
- 라이트/다크 테마: CSS 변수를 `:root`, `@media (prefers-color-scheme: dark)`, `:root[data-theme="dark"]`, `:root[data-theme="light"]` 네 곳에 동일하게 정의 (템플릿 참고)

## 비주얼 스타일
- 목표: 일본 애니메(강철의 연금술사급) 그림체
- 원칙: 그림은 장식이 아니라 이해를 서포트하는 장치. 시대적 배경 반영 필수
- 핵심: 사물만 보여주지 말고 **사람이 그 순간을 겪는 장면**으로 연출 (예: 얼어붙은 시트에 앉으며 움츠리는 사람, 스케치하며 눈을 반짝이는 엔지니어)
- 스타일 키워드: bold ink outlines, cel-shading, manga speed lines, dramatic lighting
- 색 코드: 온기=붉은주황(`--heat`), 냉기=파랑(`--cold`), 아이디어=금색(`--accent-2`), 효율=청록(`--accent`)

## 이미지 생성
- 1순위: `mcp__Canva__generate-design` (`design_type: "poster"`)로 실제 AI 일러스트 생성. 카드당 후보 4개 반환됨
- 레이트리밋 있음 — 한 번에 2~3장씩만 요청, 병렬 호출 남발 금지
- 캔바가 막히면 즉시 템플릿의 손그림 SVG 방식(`seat` 모티프 참고 — 반복 오브젝트 + `sparkle`/`tint`/`focusLines` 헬퍼)으로 폴백. 이미지 없이 방치하지 않는다

## 제작 절차 (9단계)
1. 주제 입력
2. 사실 조사 — 출처 기반, 불확실한 부분은 "확인 필요"로 표시, 추측 금지
3. 스토리 구성 — 10칸 뼈대에 tag/era/title/body 채우기
4. 비주얼 브리프 — 카드별 인물+시나리오+애니메 스타일 프롬프트
5. 이미지 생성 — 캔바 우선, 막히면 SVG 폴백
6. 카드 조립 — `template/card-template.html`을 복사해 `stories/<슬러그>.html`로, `DATA`만 교체
7. 검증 — Playwright로 라이트/다크 모드 렌더 확인
8. 배포 — Artifact로 게시 + `stories/`에 커밋
9. 아카이브 등록 — `archive.html`에 제목/카테고리·시대/한줄설명/링크 추가 여부를 사용자에게 확인
