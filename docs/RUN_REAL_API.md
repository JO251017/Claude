# 네이버 API 연결하기 (처음 한 번)

1~6장: 1단계 클릭 추이 자동 조회(데이터랩). 7장: 0단계 키워드 발굴(검색광고 + 쇼핑 검색).

## 데이터랩 자동 조회

클릭 추이(trends.csv)를 손으로 옮겨 적지 않고, 프로그램이 **네이버 데이터랩 쇼핑인사이트 공식 API**로 직접 받아오게 하는 방법입니다.
규격: `docs/api/naver_datalab_shopping_keywords.md` (공식 문서 요약). 하루 호출 한도 1,000회, 키워드 1개당 1회 호출.

## 1. API 키 발급 (5분)
1. https://developers.naver.com 로그인 → **Application > 애플리케이션 등록**
2. 사용 API에서 **데이터랩(쇼핑인사이트)** 선택 → 등록
3. 발급된 **Client ID**, **Client Secret** 확인 (이 값은 채팅·메일·문서 어디에도 붙여넣지 마세요)

## 2. 키 넣기
`.env.example`을 `.env`로 복사하고 두 줄을 채웁니다. `.env`는 git에 올라가지 않습니다.
```
NAVER_CLIENT_ID=발급받은 아이디
NAVER_CLIENT_SECRET=발급받은 시크릿
```

## 3. 약관 확인 표시
네이버 개발자센터 이용약관을 확인한 뒤 `config.yaml`에서 바꿉니다.
```
datalab:
  api_terms_ack: true
```

## 4. 키워드에 분야 코드 넣기
`data/input/keywords.csv`에 `category` 칸을 채웁니다. 네이버쇼핑에서 해당 카테고리를 누르면 주소창에 나오는 `cat_id=` 뒤 숫자입니다.
```
keyword,category
접이식 정리함,50000000
```
분야 코드가 빈 키워드는 호출하지 않고 "조회 실패(분야 코드 없음)"로 표시됩니다.

## 5. 실행
```
python -m src.cli run --source datalab
```
- 키가 없으면 **빠진 키 이름만** 보여 주고 멈춥니다. 키 값은 화면·로그·엑셀·DB 어디에도 기록되지 않습니다.
- 받아온 월별 값(ratio)은 성장률 계산에만 쓰고 저장하지 않습니다(DEC-008). 엑셀에는 성장률만 나옵니다.
- 429(호출 과다)는 Retry-After를 따르거나 1·2·4초 간격으로 최대 3회, 500·타임아웃은 최대 2회 다시 시도합니다. 403은 앱에 데이터랩 API 권한이 없다는 뜻이니 1번을 다시 확인하세요.

## 6. 처음 한 번은 직접 맞춰 보기 (권장)
키워드 3개를 골라 https://datalab.naver.com 쇼핑인사이트 화면(같은 분야, 월간, 이번 달 제외 최근 15개월)과 엑셀의 클릭 증가율을 비교합니다.

| 키워드 | 최근 3개월 값 | 1년 전 같은 3개월 값 | 수기 계산: 평균(최근3)/평균(1년전3) − 1 | 엑셀 클릭 증가율 | 일치 |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

## 7. 키워드 발굴(0단계) 키 설정
규격: `docs/api/naver_searchad_keywordstool.md`, `docs/api/naver_search_shop.md`

1. **검색광고 키**: https://manage.searchad.naver.com 로그인 → 도구 → API 사용 관리 → 라이선스 생성.
   `.env`에 `NAVER_AD_API_KEY`(액세스 라이선스), `NAVER_AD_SECRET_KEY`(비밀키), `NAVER_AD_CUSTOMER_ID`(고객 ID)를 채웁니다.
2. **쇼핑 검색 권한**: 1장에서 만든 개발자센터 앱의 API 설정에서 **'검색'**도 선택합니다(같은 NAVER_CLIENT_ID/SECRET 사용). 빠지면 403.
3. 약관 확인 후 `config.yaml`에서 `discovery.api_terms_ack: true`.
4. 실행: `python -m src.cli discover`
- 쇼핑 검색은 하루 25,000회까지. 한 번 실행에 상품 수 조회는 `discovery.max_candidates`(기본 100)개까지만 합니다(월간 검색수 많은 순).
- 확인 필요: 검색광고 키워드도구는 공식 문서에 호출 한도와 띄어쓰기 허용 여부가 없습니다. 씨앗 키워드가 실패하면 그 씨앗만 "조회 실패"로 표시되니, 실패하면 띄어쓰기를 뺀 단어로 다시 해 보세요.

## 8. 연결 점검 (키를 넣은 직후 1회)
`.env`를 채운 뒤 아래를 실행하면 공식 API 3종에 각 1회만 호출해 `[정상]`/`[실패]`와 원인만 보여 줍니다. 키 값과 응답 내용은 출력하지 않습니다.

    python -m src.cli check

- 실패 원인 예: `.env에 없음: 이름`, `키 값이 맞지 않습니다`(401), `권한이 없습니다`(403, 사용 API 선택·서비스 환경 확인), `호출 한도`(429).
- 이 점검은 호출 한도(데이터랩 하루 1,000회 중 1회, 쇼핑 검색 1회, 검색광고 1회)를 소모합니다.
