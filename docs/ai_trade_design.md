# AI 거래 특화 재구성 설계안 (초안, 승인 전 - 코드 변경 없음)

## 1. 목표
2027년부터 늘어날 AI 에이전트 간 거래(에이전트가 후보를 평가·제안하고, 상대 에이전트/사람이 승인)에 맞춰, 현재 CLI 중심 구조를 **AI가 호출하는 인터페이스 + AI 거래용 판정 기준** 구조로 바꾼다.

## 2. 구조 (기존 코어는 유지, 어댑터만 추가)
```
[Claude: MCP 서버]  [GPT: 함수/액션 어댑터]  [CLI(현행)]
            \            |            /
         src/service  (공통 서비스 계층: 입력/출력 JSON 스키마, 멱등키, 감사 로그)
                         |
   src/sourcing(profit) · src/discovery(market, trends) · approval · SQLite   <- 현행 코어 그대로
```
- 코어(`profit.py` 등)는 수정하지 않는다. `src/service`가 코어를 호출하고, 어댑터는 서비스만 호출한다.
- 어댑터는 얇게 유지한다. MCP를 기준 구현으로 하고 GPT용은 같은 스키마에서 생성한다.
- 확인 필요: ChatGPT "플러그인"은 이전 형태가 종료되고 Actions/앱/MCP 지원으로 바뀐 것으로 알고 있다. 착수 전 최신 공식 문서로 현재 규격을 확인한다(규격 추측 금지).

## 3. MCP 도구 안(안)
| 도구 | 성격 | 설명 |
|---|---|---|
| `evaluate_candidate` | 읽기 | C·S·M(+F)을 받아 T_min, 순이익, 판정, 사유 반환 |
| `run_batch` | 쓰기(내부) | 키워드·시세·원가 입력으로 실행, run_id 반환 |
| `get_run_summary` | 읽기 | 결론·처리 수치·이상 징후 |
| `list_pending_approvals` | 읽기 | 승인 대기 후보 |
| `record_approval` | 쓰기 | **사람 또는 위임장(mandate) 범위 내에서만** 기록 |
- 모든 쓰기 도구는 멱등키 필수, 호출한 에이전트·모델·도구·입력 해시를 감사 로그에 남긴다.

## 4. 추가 판정 기준 (제안 - 정의 필요)
| 기준 | 목적 | 현행과의 관계 |
|---|---|---|
| 에이전트·거래 상대 식별/신뢰 등급 | 누구와 거래하는지 | 신규 |
| 위임장 한도(건당·일별 금액, 허용 카테고리) | AI 자동 승인 범위 | 신규, 한도 초과는 사람 승인으로 승격 |
| 데이터 신선도 TTL(기계 판독) | 오래된 시세로 자동 거래 방지 | 최신성 7·14일 규칙을 확장 |
| 반품·분쟁 정책의 기계 판독 가능 여부 | 수량당 배송비 같은 손해 조건 사전 차단 | ship_fee_rule 확장 |
| 재현 가능성(입력 해시·설정 해시로 판정 재현) | 에이전트 간 분쟁 시 근거 | 메타 시트의 설정 해시 확장 |
- 기존 가중치 점수 금지 원칙을 유지한다. 새 기준도 사전식(탈락 > 보류 > 통과)으로만 결합한다.

## 5. 충돌하는 기존 원칙 - 결정 필요
1. **DEC-008(네이버 데이터를 AI 요청에 넣지 않음)**: MCP로 결과를 AI에게 주면 성장률 등 파생값이 AI 컨텍스트에 들어간다. 후보: (a) 네이버 파생값은 MCP 응답에서 제외, (b) 파생값만 허용(원시 시계열은 계속 금지), (c) 약관 확인 후 허용. 약관 확인 전까지 (a)를 기본으로 한다.
2. **"승인 없는 외부 쓰기 금지"**: AI 자동 승인은 위임장 한도 내로만 허용할지, 전부 사람 승인으로 둘지.
3. **PRD 8장 제외 범위**: 에이전트 간 결제·주문 실행은 이번 범위에 넣지 않는다(후보 평가·승인 기록까지만).

## 6. 단계
- 2a: 서비스 계층 + MCP 읽기 도구(`evaluate_candidate`, `get_run_summary`). 코어 무변경, 테스트로 CLI 결과와 동일성 검증.
- 2b: 승인 도구 + 멱등키·감사 로그 + 위임장 한도.
- 2c: 5의 추가 기준 구현, GPT 어댑터.
- 각 단계 pytest 통과 후 커밋, 코어 변경이 필요하면 먼저 확인.
